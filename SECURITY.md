# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting for this repository (**Security → Report a
vulnerability**), or contact the maintainer directly through the profile
listed on the repository. You will get an acknowledgement within a few days.

## Scope

This is a personal open-source project. Reports about the code in this
repository, its build and release workflows, and its published artifacts are
in scope. Third-party services it talks to are not.

## Supported versions

Only the default branch and the latest release receive fixes.
